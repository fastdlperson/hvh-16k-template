# Recommendations
These will mainly be US vps providers, because im from the US and used all of these with [pterodactyl-installer](https://github.com/pterodactyl-installer/pterodactyl-installer)

## 1. [Physgun (P-VPS-4)](https://physgun.com/vps)
**Pros**
- Cheap
- Reliable uptime  
- DDoS protection
- Great customer support

**Cons**
- Not alot of loctaions
- No EU loctaions unless you consider the UK.

## 2. [Kyun](https://kyun.host/)
**Pros**
- Cheaper than any other host
- Reliable uptime  
- Customizable specs

**Cons**
- No DDoS protection
- Not alot of loctaions

## 3. [OVH](https://ovhcloud.com/)
**Pros**
- It's OVH
- Has a ton of loctaions

**Cons**
- It's OVH

## 3. [NFOservers Game Server](https://www.nfoservers.com/order.php)
**Pros**
- You get a % off for "in X month chunks"
- Reliable uptime  
- DDoS protection
- Has a ton of loctaions

**Cons**
- Windows unless you want to pay $10000000 dollars for linux
- You pay per player slot so you can have 32 slots without paying which is $38.4
- The worst game panel ive used
- Randomly changes server.cfg
- Can not change startup command 
- If you are trying to debug a plugin, the RCON sucks, it doesn't show the true server logs half the time too
- Really not so userfriendly
- The worst game server ive ever used (again I have ptsd)
- The WORST RCON ive used (again)
